# 8086 Assembly Basics

This repository contains a collection of simple 8086 Assembly language programs created as part of the Computer Architecture course.

The programs demonstrate fundamental Assembly concepts such as:

- Character output
- BIOS and DOS interrupts
- String display
- Basic program structure

## Programs

### Print Name

Displays a name character by character using BIOS video interrupt (INT 10h).

File:
- `print-first-name.asm`

---

### Display 7×7 Asterisk Square

Prints a 7×7 square of asterisks using DOS interrupt services (INT 21h).

File:
- `display-asterisk-square.asm`

## Environment

- 8086 Assembly
- DOS
- EMU8086
